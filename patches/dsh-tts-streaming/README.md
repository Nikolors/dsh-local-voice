# Потоковая озвучка для @goodandready/dsh-tts

Штатно плагин озвучки ждёт готовое сообщение (`assistant/message`) и только потом
начинает синтез. Приложение при этом отдаёт живой текст событием
`agent/assistant-stream` — плагин его просто не слушает.

Эта правка добавляет подписку: текст копится по кадрам `chunk/text-delta`, на
границах предложений уходит в `speakPiece`, остаток — на кадре `end`. Чтобы
готовый ответ не читался второй раз, `assistant/message` пропускается, если поток
уже говорил в этой сессии последние 60 секунд.

## Как применить

1. Найдите установленный пакет плагина, например
   `%USERPROFILE%\.dsh\profiles\<профиль>\node_modules\@goodandready\dsh-tts\lib\session-events.js`.
2. Сделайте копию файла.
3. Замените его файлом `session-events.js` из этой папки.
4. Перезапустите приложение.

Вернуть как было — скопировать копию обратно и перезапустить.

## Проверка

Если задать переменную среды `DSH_TTS_STREAM_LOG` (путь к файлу), правка будет
писать туда строки «событие потока», «фраза в потоке» и «озвучено кусков» — по ним
видно, что поток доходит.

## Ограничения

- Заметный выигрыш только на длинных ответах: короткие реплики и так синтезируются
  быстро.
- Правка живёт в чужом пакете: обновление плагина её перезапишет, тогда файл нужно
  положить снова.
