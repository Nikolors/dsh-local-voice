# Голосовой сервер вместе с приложением

Плагин следит за локальным сервером озвучки Qwen3-TTS (порт 8895) и держит его
в одном жизненном цикле с приложением DeepSeek Harness.

## Что делает

- **При запуске приложения** проверяет порт 8895. Если сервер уже слушает —
  ничего не трогает. Если порта нет — запускает `pythonw.exe` с сервером
  озвучки в фоне, без окна консоли, и ждёт, пока порт откроется (до минуты).
- **При выходе из приложения** гасит запущенный им процесс вместе с дочерними.
- Если сервер не поднялся, пишет предупреждение в журнал приложения и не
  мешает работе: голос просто не зазвучит, пока сервер не поднимут вручную.

## Настройки

Настройки задаются в строке плагина в `cordis.patch.yml`:

- `port` — порт сервера озвучки, по умолчанию 8895;
- `pythonw` — путь к `pythonw.exe` окружения;
- `script` — путь к `qwen_tts_server.py`;
- `talker` — файл модели (по умолчанию `qwen-talker-1.7b-base-Q8_0.gguf` для
  клонирования голоса);
- `refWav` — образец голоса 24 кГц моно;
- `lang` — язык синтеза, по умолчанию `russian`;
- `stress` — `1` включает словарь ударений (по умолчанию выключен: без LoRA
  ударения ухудшают звучание).

## Ограничения

- Видеопамять: сервер занимает около пяти гигабайт из восьми. Для игры его
  нужно останавливать, иначе не хватит места.
- Плагин не запускает сервер, если тот уже работает: внешний процесс остаётся
  внешним, плагин его не гасит.

## Проверка

1. Запустить приложение и убедиться, что порт 8895 слушает.
2. Выйти из приложения и убедиться, что процесс `pythonw.exe` с сервером исчез.
